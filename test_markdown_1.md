## Introduzione
Questo è il primo file markdown di test. Contiene una struttura base con vari elementi di formattazione.

## Sezioni Principali

### 1. Formattazione Testo
- **Testo in grassetto**
- *Testo in corsivo*
- ***Testo in grassetto e corsivo***
- ~~Testo barrato~~

### 2. Liste
#### Lista non ordinata
- Elemento 1
- Elemento 2
  - Sottoelemento 2.1
  - Sottoelemento 2.2
- Elemento 3

#### Lista ordinata
1. Primo elemento
2. Secondo elemento
3. Terzo elemento

### 3. Tabella di Esempio
| Colonna 1 | Colonna 2 | Colonna 3 |
|-----------|-----------|-----------|
| Dato A    | Dato B    | Dato C    |
| Dato D    | Dato E    | Dato F    |

```python
def saluta(nome):
```
